# 韓國代購報價網站

手機用的報價紀錄網站：選分類、填品名／成本／報價／數量，就會即時提醒是否低於底線。資料存在 Google 試算表，也可以從網站匯出 Excel。

## 一次性設定（約 5 分鐘）

### 1. 建立 Google 試算表後端
1. 打開雲端硬碟裡已建好的試算表「韓國代購紀錄 11/27–12/2」（分頁：總覽、紀錄、分類統計、規則、說明）。
2. 上方選單 **擴充功能 → Apps Script**。
3. 把 `apps-script/Code.gs` 的內容全部貼上，取代原本的程式碼。
4. 最上面的 `const KEY = '請改成你們的密碼';` 改成你們自己的密碼，按儲存。
5. 右上角 **部署 → 新增部署作業**：
   - 類型選 **網頁應用程式**
   - 執行身分：**我**
   - 誰可以存取：**所有人**
6. 按部署，第一次會要求授權，照畫面允許。
7. 複製「網頁應用程式網址」（結尾是 `/exec`）。

> 第一次有資料寫入時，試算表會自動新增「紀錄」工作表。也可以直接在試算表裡手動加列，網站下次同步就會讀到。

### 2. 手機上設定
1. 用手機打開網站，第一次會自動跳出「連線設定」。
2. 貼上剛剛的 `/exec` 網址、填密碼、填你的名字，按「儲存並連線」。
3. 兩個人各自在自己的手機設定一次。
4. 建議用 Safari「分享 → 加入主畫面」，之後像 App 一樣開啟。

## 使用說明
- **報價**：選分類 → 填品名、成本、報價 → 調整數量 → 加入紀錄。
- **查詢**：可搜尋、篩選「低於底線／建議不接」，資料依分類分組，點商品可以編輯或刪除。
- **匯出 Excel**：在查詢頁，會下載「紀錄」和「分類統計」兩張工作表。
- **網路不穩**：資料會先存在手機，畫面顯示「尚未上傳」，有網路時自動補傳。

## 要改規則或行程
打開 `index.html`，最上面 `行程設定` 區塊：
- `TRIP`：地點、日期、人數、旅程總成本（目前 50,080）
- `RULES`：各分類「每件最少毛利、最低毛利率」
- `REJECT_PCT`：毛利率低於多少建議不接（目前 10%）

## 安全
網址和密碼只存在各自手機裡，不會放在 GitHub 上。如果密碼外流，到 Apps Script 改 `KEY` 後重新部署（部署 → 管理部署作業 → 編輯 → 新版本）。
